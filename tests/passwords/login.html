Veyscape password manager test

Serve over http (e.g. npm run dev, then http://localhost:1420/tests/passwords/login.html); the password script does not run on file:// pages.

1. Login that navigates

Submit: the page reloads as "signed in" and Veyscape offers to save.

2. Single-page login (no navigation)

Password wrong: an error, the form stays, no offer. Anything else: the form goes away and Veyscape offers to save.
